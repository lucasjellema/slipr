Then

  1. Paste the instruction into a new chat and send it. When the chat says it is too long, attach the downloaded .md file instead.
  2. Save the chatbot's answer (the code block) as show.json in a new folder. Pictures are placeholders: their descriptions tell you which images to put in the folder's images/ folder.
  3. Open the viewer and choose Open a show folder….
  4. When the viewer lists errors, click Copy fix-up prompt and send that to the same chat.

Nothing you type here leaves this page: it only builds the text you copy. More in the user manual.
