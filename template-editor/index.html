Slipr Template Editor

Make a template

Start from one of Slipr's templates and change its colours, fonts and sizes, or arrange new layouts, while you watch sample slides. Save the result as a template folder or a .zip.

Edit a template in place, for example one in Slipr's templates/ folder.

New template

Lower case letters, digits and hyphens. Shows refer to the template by its folder, which gets this name.

Add a font file

The file is copied into the template's assets/fonts/ folder, so shows present offline. Check that its licence allows that.

New layout

A composed layout: you place its slots and pictures on the slide. It is saved as layouts/<id>.html and a marked block at the end of theme.css.

Shows refer to the layout by its id.

Add a slot

Shows store the slot's content under this name (title, body, photo).

How one of the template's layouts draws this kind of slot.

Add a picture

A logo or a decoration, the same on every slide with this layout. Readers on a phone do not see it.

A new file is copied into the template's assets/decor/ folder.
